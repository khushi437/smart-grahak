# 🛒 Smart Grahak Management System
A web-based **Customer and Payment Management System** developed using Laravel, PHP, MySQL and Bootstrap.


## 📌 Project Overview
Smart Grahak is a web application designed to help manage customer information and payment-related records in an organized way.
The system provides a simple interface for managing customers, recording payments and viewing important information.


## ✨ Features

- 👤 Customer Management
- ➕ Add New Customer
- ✏️ Edit Customer Details
- 🗑️ Delete Customer
- 💳 Payment Management
- 📋 View Customer Records
- 📊 Manage Payment Information
- 🔍 Easy-to-use Interface
- 📱 Responsive Design
- 🗄️ MySQL Database Integration

## 🛠️ Technologies Used

- PHP
- Laravel
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
